## 6. Cross-cutting request, observation and media contract

Before any new adapter is enabled, its typed schema must specify:

1. **Identity:** distinct client request key/hash, accepted operation, journal job, physical attempt/generation, source/include/canonical/dependency identities, profile revision, policy/checkpoint/server identity and final artifact/receipt. Keep original authority identifiers; no fabricated aliases or latest-file discovery.
2. **Effects and ownership:** classify read/local proposal, disk persistence, provider inference, GPU work, graph write and display/input authority separately. Preserve Origin/CSRF and single-operator scope. Credentials remain in existing private grants, never URLs, durable requests, logs, exported CLI arguments or browser persistent storage. Never expires disables only the key timer, not session/end/restart cleanup.
3. **Admission/recovery:** strict finite/bounded fields; reject unsupported combinations; freeze effective budgets/profile/source. Return exact handles and a disposition path after acceptance. Same key/different payload conflicts; observe accepted work without new grants. Revalidate authorization at dispatch. Unknown physical completion is not retry authority. New generic operations must not weaken existing generation/publication protocols.
4. **Observation:** use existing journal/SSE replay and snapshot watermark. Pagination is presentation over a consistent inventory, not a change to runnable-job selection. Parent/child counts include all predeclared children. Queries/refetch/navigation do not dispatch work. Preserve exact accepted handles across disconnect and distinguish unknown from failed/zero.
5. **Cancellation/cleanup:** request cancel through E024 for underlying jobs, not by killing unrelated processes. Child boundaries retain completed generation/episodes/artifacts. Warm snapshots retain a GPU lease (W/snapshot_process.py:89–148); verified retirement/handoff precedes build/evaluation/viewport allocation. Unknown descendant or lease cleanup blocks new ownership. Independently owned policy servers survive.
6. **Artifacts:** manifests name exact scene/run/policy/source, media type/size/hash, completion status, raw counts and missing evidence. Reject nonfinite/mismatched metrics. Preserve partial/failed/zero-episode output; unknown is not zero success. Resolve opaque IDs under approved roots; deny traversal/symlinks and MIME confusion; authorize every range request. Default executable reports to attachment-only until separate-origin/sandbox/CSP handling is verified.
7. **Viewport media/input:** compatible NVIDIA signaling/client, authenticated signaling/media/input, one explicit controller lease, bounded duration/FPS/resolution/input/queue/storage, revocation and disconnect behavior. Use typed rate-limited camera/pick messages over the approved transport rather than one HTTP call per motion. Bind commands/results to viewport generation, source and actually observed frame/stage identity; reject stale associations. ovstage ordinals are publication gates, not historical snapshots. A past frame cannot claim matching prim metadata unless that correspondence was actually retained/verified.
8. **Readback:** accepted is not persisted, persisted is not published, rendered is not simulated, cancelled is not cleaned up. Each effect has exact-target readback with verified bytes/identity; a successful HTTP status alone does not satisfy the UI success state.
