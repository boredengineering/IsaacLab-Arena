## 1. Architectural Decisions

1. **Two synchronized representations, one source of truth**:
   - `ArenaEnvGraphSpec` (Pydantic) remains canonical.
   - `rdf_lowering.py` provides bidirectional lift/lower: `spec_to_rdf_graph()` and `lower_rdf_graph_to_spec()` (SPARQL-driven).
   - `lpg_neo4j_sync.py` mirrors the same spec into Neo4j as a Labeled Property Graph for Cypher traversal.

2. **RDF-star reification for uncertain spatial relations**:
   - `ReifiedRelationSpec` carries `delta_x/y/z` continuous intervals, `required_headroom`, `required_friction`, `kinematic_manifold`, and `prior_entropy`/`posterior_entropy`.
   - Reifiers become first-class nodes (`arena:ReifiedRelation`) so belief updates annotate the *statement*, not just the entities.

3. **Ontology + constraints**:
   - `ontology/arena_schema.ttl` — classes (EnvironmentGraph, SceneEntity, Embodiment, Fixture, Furniture, USDPrim, SurfaceAnchor, RigidObject, Receptacle, Camera, EvaluationRun) and object properties.
   - `ontology/arena_constraints.shacl.ttl` — pre-simulation structural validation.
   - `ontology/arena_context.jsonld` — JSON-LD context for spec interchange.

4. **Provenance**: every generated environment emits `lineage.ttl` (PROV-O activities/derivations) alongside a human-readable `lineage.json`.
