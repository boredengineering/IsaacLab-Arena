# Plan to Implement GR00T Policy for G1 with Brainco Hands

This document outlines the systematic plan to integrate and evaluate a **GR00T Closed-Loop Policy** for the **Unitree G1 humanoid robot equipped with Brainco dexterous hands** using the standard 43-DoF G1 model config.

---

## 1. Role and Interaction of Configuration Paths

The configuration files in `isaaclab_arena_gr00t/embodiments/g1/` match the `nvidia/GN1x-Tuned-Arena-G1-Loco-Manipulation` model expectations perfectly:

1. **`modality_config_path` (`g1_sim_wbc_data_config.py`):**
   - **Role**: Registers the multi-modal *data schema* expected by the neural network checkpoint (sequence length, ego_view keys, action/state layout).
   - **Why it matters**: It configures how the multi-step look-ahead actions and image streams are packed/unpacked before policy inference.

2. **`policy_joints_config_path` (`gr00t_43dof_joint_space.yaml`):**
   - **Role**: Defines the internal layout, grouping, and ordering of joints inside the policy network (e.g., anatomical groups like `left_leg`, `left_arm`, `left_hand`).
   - **Why it matters**: The neural network is shape-sensitive and expects joints in the exact 43-DoF sorted groups it was trained on.

3. **`state_joints_config_path` (`43dof_joint_space.yaml`):**
   - **Role**: Translates flat simulator state observations (which follow URDF/USD order) into named joints.
   - **Why it matters**: Allows the policy runner to map the flat simulator index array to specific joint names, matching them to `policy_joints_config_path`.

4. **`action_joints_config_path` (`43dof_joint_space.yaml`):**
   - **Role**: Translates named joint targets generated by the policy back into flat simulation command indices.
   - **Why it matters**: Ensures target angles are dispatched to the correct physics joints in the simulator.

---

## 2. Solution: 5-Finger Manipulation with a 3-Finger Policy (Mimic Coupling)

Since the G1 model is trained on a 43-DoF body (supporting 3-finger hands: thumb, index, middle), the extra fingers of the Brainco dexterous hand (ring and pinky) are not natively controlled by the model.

### Coupling / Mimic Strategy
To achieve a secure and stable grasp using the 5-finger Brainco hands, the `G1BraincoWBCAction` term can dynamically couple the targets of the extra fingers (`ring` and `pinky`) to mimic the target values of the `middle` finger:

- `left_hand_ring_0_joint` target = `left_hand_middle_0_joint` target
- `left_hand_ring_1_joint` target = `left_hand_middle_1_joint` target
- `left_hand_pinky_0_joint` target = `left_hand_middle_0_joint` target
- `left_hand_pinky_1_joint` target = `left_hand_middle_1_joint` target

This allows the high-level policy to run in standard 43-DoF mode while yielding a cohesive 5-finger grasp in the physics simulator.

### Step 2: Adapt `G1BraincoWBCAction` with Mimic Coupling

Update the action term to automatically map the extra finger joints to mimic middle finger actions during post-processing.

*File*: `g1_brainco_extension/embodiments/mdp/actions/wbc_action.py`  
```python
class G1BraincoWBCAction(G1DecoupledWBCJointAction):
    def process_actions(self, actions: torch.Tensor):
        self._raw_actions[:] = actions
        
        # 1. Slice commands from the end of the action vector
        navigate_cmd = self.get_navigation_cmd_from_actions(actions)
        base_height_cmd = self.get_base_height_cmd_from_actions(actions)
        torso_orientation_rpy_cmd = self.get_torso_orientation_rpy_cmd_from_actions(actions)
        
        # 2. Update WBC goal
        self.set_wbc_goal(navigate_cmd, base_height_cmd, torso_orientation_rpy_cmd)
        self.wbc_policy.set_goal(self._wbc_goal)
        
        wbc_obs = self._prepare_brainco_observations()
        
        actions_np = actions.clone().cpu().numpy()
        sim_target_full_body_joints = actions_np[:, : self.num_joints]
        
        wbc_target_full_body_joints = self._brainco_convert_sim_to_wbc(
            sim_target_full_body_joints, self._asset.data.joint_names
        )
        
        wbc_target_upper_body_joints = wbc_target_full_body_joints[
            :, self.robot_model.get_joint_group_indices("upper_body")
        ]
        
        # 3. Execute WBC policy
        self.wbc_policy.set_observation(wbc_obs)
        wbc_action = self.wbc_policy.get_action(wbc_target_upper_body_joints)
        
        # 4. Post-process (maps 43 WBC actions to simulation joints)
        self._processed_actions = postprocess_actions(
            wbc_action, self._asset.data, self.wbc_g1_joints_order, self.device
        )
        
        # 5. Apply Mimic Coupling for Brainco finger joints (ring and pinky)
        # Find index of left/right middle finger joints in asset data
        middle_joints = {
            "left_0": self._asset.data.joint_names.index("left_hand_middle_0_joint"),
            "left_1": self._asset.data.joint_names.index("left_hand_middle_1_joint"),
            "right_0": self._asset.data.joint_names.index("right_hand_middle_0_joint"),
            "right_1": self._asset.data.joint_names.index("right_hand_middle_1_joint"),
        }
        
        # Define joints that mimic the middle finger targets
        mimic_map = {
            "left_hand_ring_0_joint": middle_joints["left_0"],
            "left_hand_ring_1_joint": middle_joints["left_1"],
            "left_hand_pinky_0_joint": middle_joints["left_0"],
            "left_hand_pinky_1_joint": middle_joints["left_1"],
            "right_hand_ring_0_joint": middle_joints["right_0"],
            "right_hand_ring_1_joint": middle_joints["right_1"],
            "right_hand_pinky_0_joint": middle_joints["right_0"],
            "right_hand_pinky_1_joint": middle_joints["right_1"],
        }
        
        for joint_name, source_idx in mimic_map.items():
            if joint_name in self._asset.data.joint_names:
                target_idx = self._asset.data.joint_names.index(joint_name)
                self._processed_actions[:, target_idx] = self._processed_actions[:, source_idx]
```

### Step 3: Run the Closed-Loop Policy

```bash

    --policy_type isaaclab_arena_gr00t.policy.gr00t_closedloop_policy.Gr00tClosedloopPolicy \
    --policy_config_yaml_path g1_brainco_extension/policy/config/g1_brainco_static_gr00t_closedloop_config.yaml \
    --num_steps 1000 \
    --external_environment_class_path g1_brainco_extension.environments.g1_static_pick_and_place_drink_env:G1StaticPickAndPlaceDrinkEnvironment \
    g1_static_pick_and_place_drink \
    --object beer_bottle
```
