## 2. Reinforcement Learning Architecture Built

### A. Pure-Tensor Reward Engine (`isaaclab_arena/tasks/rewards/pick_and_place_rewards.py`)
Dense reward functions designed to prevent early Kit import conflicts and ensure stable PPO gradient signals:
- `object_ee_distance`: Smooth reaching reward with tanh kernel: $r = 1.0 - \tanh(5.0 \cdot d_{\text{ee}\to\text{apple}})$.
- `object_is_lifted`: Binary lift reward ($+1.5$) active when $Z_{\text{apple}} > Z_{\text{min\_lift}}$ ($0.03\text{ m}$).
- `object_destination_distance`: Transport shaping: $r = 1.0 - \tanh(2.0 \cdot d_{\text{apple}\to\text{plate}})$.
- `object_placed_bonus`: High-value placement bonus ($+3.0$) when apple is within destination radius ($0.075\text{ m}$) and lifted above table.
- `action_rate_l2`: Action smoothness regularizer ($-0.01 \cdot \|\mathbf{a}_t - \mathbf{a}_{t-1}\|^2$) suppressing humanoid joint jitter.

### B. Privilege & Observation State Space (`isaaclab_arena/tasks/pick_and_place_task_rl.py`)
- Standardized to a flattened **152-dimensional observation vector** (136-D joint proprioception + 16-D privileged relative positions in the robot base frame: `object_pos`, `dest_pos`, `ee_pos`, `ee_to_object`, `object_to_dest`, `is_lifted`).
- Disabled unconcatenated 4x4 matrix terms (`right_wrist_pose_pelvis_frame`, `left_wrist_pose_pelvis_frame`) and empty `wbc` observation groups to ensure pure 2D tensors `(num_envs, 152)` for RSL-RL.
- Added dynamic termination function `pick_and_place_rl_success`:
  - When `rl_training_mode=True`: returns `torch.zeros(num_envs, bool)` to satisfy `SuccessRecorder` assertions without terminating episodes prematurely.
  - When `rl_training_mode=False`: evaluates geometric placement $(d_{xy} < 0.075\text{ m}) \land (Z > 0.03\text{ m})$.

### C. Environment Registration (`isaaclab_arena_environments/g1_apple_to_plate_rl_environment.py`)
- Registered environment `g1_apple_to_plate_rl` with Unitree G1 whole-body control (`g1_wbc_agile_joint`), high-friction finger contact materials (`static: 6.0, dynamic: 5.0`), and C1 tabletop poses.
- Linked to `base_rsl_rl_policy:RLPolicyCfg` for IsaacLab Hydra interoperability.

## 4. Evaluation Diagnostic Learnings

During empirical testing of the trained policy:

1. **Missing GUI (`--viz kit`)**:
   In Isaac Sim 6.0 and Isaac Lab 3.0, headless mode is the built-in default when `--viz` is omitted. To display the interactive Omniverse Kit 3D window on the desktop, `--viz kit` must be passed explicitly.
2. **`success_rate: 0.0` Explanation**:
   `G1AppleToPlateRLEnvironmentCfg` was registered with `rl_training_mode: bool = True`. When `rl_training_mode` is True, `pick_and_place_rl_success` returns all False so RL training is not halted prematurely. In evaluation, this caused `SuccessRecorder` to always read 0.0.
   **Remedy**: Set `rl_training_mode: bool = False` during evaluation so physical placement on the plate is measured.
3. **`object_moved_rate: 1.0`**:
   The independent spatial recorder confirmed that in 100% of evaluation episodes, the G1 robot physically moved the apple.
4. **Episode Duration (~3.0s)**:
   Episodes terminate via `object_dropped` if the apple falls below the table threshold ($Z < -0.05\text{ m}$).

## 7. DCRG Recurrent Loopback & RDF-star Knowledge Graph Synchronization

### A. Root Cause Discovery: WBC Ground Depenetration Transients in `play.py`
- **Symptom**: In raw IsaacLab `play.py`, the G1 humanoid topples backwards immediately at step 0 without reaching or picking.
- **Root Cause**: `play.py` lacks a pre-roll settling loop and immediately queries the policy at step 0 during initial PhysX foot-ground contact depenetration. The resulting normal-force impulse combined with dynamic arm reach shifts the Center of Mass (CoM) behind the ankle support polygon.
- **Remediation**: `policy_runner.py`'s 40-step pre-roll (`verify_and_settle_scene`) with neutral posture hold (`build_neutral_hold_action`, commanding 0.75m standing pelvis height) damps contact shock and achieves 70%–100% placement success.
