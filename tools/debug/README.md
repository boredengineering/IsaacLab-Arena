# Debug Tools

This folder contains the largest collection of scratch scripts, created for deep-diving into the Whole Body Controller (WBC) and Isaac Sim configurations. These scripts are typically run to isolate very specific, localized issues, such as:
- Joint order mismatches (`debug_joint_order.py`, `debug_joints.py`)
- Kinematic structure flaws (`debug_arms.py`, `debug_crouch.py`, `debug_base_height.py`)
- Output data inspection (`debug_npz.py`, `debug_npz2.py`)
- Action target verification (`debug_cmds.py`, `debug_wbc_action.py`)
