## 1. Source-backed findings

These findings describe the planning baseline above, not the post-G1 implementation. The G1 handoff below records implemented corrections and actual decoder/check results; remaining installed and empirical obligations are not promoted by them. Source links are repository-relative. No protected simulator, Docker, CI, credential or shared-service investigation is required to act on them.

### R1 — Canonical identity is a migration boundary

[contracts.py:389–455](../../../../isaaclab_arena/agentic_environment_generation/workflow/contracts.py#L389) hashes the model's complete serialized form. Adding default parameter/policy fields can change old canonical bytes and break same-key replay, grants, profiles and evidence even if old numerical defaults look unchanged. [NativeCaptureSettings.compatible_bytes](../../../../isaaclab_arena/agentic_environment_generation/workflow/native_capture.py#L134) already preserves an old optional-field omission. G1 must version decoding/serialization and prove old public contract/profile/evidence identities remain unchanged. Do not globally remove legacy schema-specific safeguards.

### R2 — Parameterizing the evaluator alone leaves a hidden native veto

[scene_observation.py:163–172](../../../../isaaclab_arena/agentic_environment_generation/workflow/scene_observation.py#L163) uses fixed thresholds and one criterion subject; [native_capture.py:64–79](../../../../isaaclab_arena/agentic_environment_generation/workflow/native_capture.py#L64) pins several values. More importantly, [native_realization.py:18–30,194–260](../../../../isaaclab_arena/agentic_environment_generation/workflow/native_realization.py#L18) has `LINEAR_SPEED_LIMIT`, no linear-limit field in `NativeSettleSettings`, and raises `SceneSettleRejected`. [NativeCaptureProducer](../../../../isaaclab_arena/agentic_environment_generation/workflow/native_capture.py#L668) wraps that as a failed capture before normal assessment. New parameters must reach mechanics, sampling, retained reports and evaluation. A complete finite measurement that violates a chosen criterion must not automatically become an integration failure. Keep reset/termination, invalid data, unsafe execution and retention failures distinct.

### R3 — The existing ternary codec is not a general temporal/aggregation codec

[visual_request and validate_visibility_response](../../../../isaaclab_arena/agentic_environment_generation/workflow/scene_observation.py#L229) require a dense window, bounded frames, one ordered camera occurrence for `visibility-v2`, exact answer ordering and a hardwired ALL-style fold. The response does not explicitly identify step/modality, and its limitations say retained imagery. The full-scene implementation needs versioned frame identities and declared camera/subject/time aggregation; simply calling the I02 parser is insufficient. Preserve the old codec's meaning. Core evidence already has inconclusive verdicts—do not build a parallel truth framework.

### R4 — Differing windows affect requests, restoration and displacement, not only DTOs

[evidence_contracts.py:19–68](../../../../isaaclab_arena/agentic_environment_generation/workflow/evidence_contracts.py#L19) requires a common window. [_window](../../../../isaaclab_arena/agentic_environment_generation/workflow/scene_observation.py#L129) requires the entire sample sequence to match the criterion. [scene_ports.py:393–486](../../../../isaaclab_arena/agentic_environment_generation/workflow/scene_ports.py#L393) selects a displacement sample from the capture-window start and restores exactly one measured manifest plus at most one visual manifest. New sparse/multi-stream coverage must reach all these consumers. Retain coherent candidate/reset/clock identities and deterministic selected-evidence ancestry; never fuse unrelated cohorts to satisfy a conjunction.

### R5 — Retained threshold exploration is a new derivation, not ordinary replay

[NativeCaptureProducer.replay](../../../../isaaclab_arena/agentic_environment_generation/workflow/native_capture.py#L294) checks the original contract/profile/settings binding. [SceneEvidenceArtifacts](../../../../isaaclab_arena/agentic_environment_generation/workflow/scene_evidence_artifacts.py#L81) binds one immutable cohort/contract/profile. Regrading with a changed full contract therefore cannot be claimed as existing functionality. Define a derived-assessment identity referencing original acquisition bytes and a new evaluation spec; expose it through an authenticated keyed application/readback path. Do not rewrite the original run or use a new criterion to claim original acceptance.

### R6 — Scheduling must control the consumed data, and byte limits still apply

[NativeImageTransform / supported](../../../../isaaclab_arena/agentic_environment_generation/workflow/native_capture.py#L36) restrict camera IDs, image count, resolution and payload size. [capture execution](../../../../isaaclab_arena/agentic_environment_generation/workflow/native_capture.py#L625) couples recording to sampled steps and calls `capture_trajectory` after settling. A frame-selection setting alone does not establish when the simulator actually rendered or whether a camera buffer is fresh. New diagnostics also cannot be silently inserted into a legacy RGB-only/single-`evidence.json` artifact protocol. Define bounded modalities/files/metadata, actual observation times and the request's eligible subset. Verify encoder, private-packet, evidence, model-request/reply and fresh-reader bounds together. The prior payload/token estimates and “80% rendering savings” were unsupported and are removed.

### R7 — Fixed existing-source execution would still enter generation-only paths

[application.py:171–201,338–350](../../../../isaaclab_arena/agentic_environment_generation/workflow/application.py#L171) requires generation ceilings for non-legacy-native modes and routes only workflow schemas 3/4 directly to scene execution. ### R9 — Unset workflow time is incompatible with current consumers and timers

[read_model.py:33–88](../../../../isaaclab_arena/agentic_environment_generation/workflow/read_model.py#L33), [GraphQL budget views](../../../../isaaclab_arena/agentic_environment_generation/workflow/api/schema.py#L395), [native_worker_protocol.py:101–123](../../../../isaaclab_arena/agentic_environment_generation/workflow/native_worker_protocol.py#L101), [foreground deadlines](../../../../isaaclab_arena_examples/agentic_environment_generation/foreground_split_scene_ports.py#L99), and [native_scene_worker.py:118–135,236–241](../../../../isaaclab_arena_examples/agentic_environment_generation/web_api/native_scene_worker.py#L118) assume finite arithmetic and an absolute one-shot process alarm. Separate optional experiment ceilings from actual transport/supervision leases, refreshable authority and cleanup rights; implement and verify the control protocol, clock conversion and stale-owner refusal.

API authentication has another independent ceiling: [server.supervise](../../../../isaaclab_arena/agentic_environment_generation/workflow/api/server.py#L148) issues a 3,600-second token; [TokenRegistry](../../../../isaaclab_arena/agentic_environment_generation/workflow/api/security.py#L50) enforces finite expiry; [installed_execution](../../../../isaaclab_arena/agentic_environment_generation/workflow/api/installed_execution.py#L147) and [installed_native](../../../../isaaclab_arena/agentic_environment_generation/workflow/api/installed_native.py#L114) capture the startup context/expiry. The [client descriptor](../../../../isaaclab_arena/agentic_environment_generation/workflow/api/client.py#L152) also expires and pins credential generation 1. Refreshing only a grant or native lease leaves later releases, reads and cancellation blocked. Assign G1 the credential-refresh/principal-rebinding protocol and G2 its secure private delivery, composition/client integration and non-sending expiry-crossing witness. Preserve exact principal/instance/scope, reject expired/revoked authentication and enforce workload authority independently; neither token refresh nor generation change renews a campaign allocation.

### R10 — Accounting-only does not require refunds or removal of all bounds

[SplitScenePorts.require_bounded_capability](../../../../isaaclab_arena/agentic_environment_generation/workflow/split_scene_ports.py#L78) still compares token/cost bounds that may be absent; [scene reservation](../../../../isaaclab_arena/agentic_environment_generation/workflow/neo4j_store.py#L3553) enforces cumulative reserved runtime. Existing [authorization renewal](../../../../isaaclab_arena/agentic_environment_generation/workflow/application.py#L948) is not budget mutation or permission to rerun a released effect.

### R12 — False visibility does not supply a causal diagnosis or repair target

The current [router](../../../../isaaclab_arena/agentic_environment_generation/workflow/scene_loop.py#L341) chooses from aggregate evidence, while [repair validation](../../../../isaaclab_arena/agentic_environment_generation/workflow/repairs.py#L275) constrains an authored delta. Neither proves that the permitted target addresses the failed proposition. Retain the failed subject/criterion/frame and a supported mechanism; require appropriate prerequisites and a permissible effective intervention. Preserve complete uncertainty and sensor conflict. Information gathering or an exploratory intervention may be selected explicitly, but is not a corrective-repair claim and cannot rewrite UNKNOWN as FALSE.

This needs an implemented consumer, not only diagnostic production: [ScenePorts.execute](../../../../isaaclab_arena/agentic_environment_generation/workflow/scene_ports.py#L260) recomputes the old router decision, [the store](../../../../isaaclab_arena/agentic_environment_generation/workflow/neo4j_store.py#L3584) converts codec-2 observe into capture, and [refiner feedback](../../../../isaaclab_arena_examples/agentic_environment_generation/foreground_scene_ports.py#L252) checks the retained aggregate assessment. G1 implements the pure selected-mechanism/target evaluator and bound decision record. G2 wires it through retained decision, reservation/release, restore/recovery and the declared refiner feedback projection. Reject a wrong-subject failure without a supported causal link to the permitted target; UNKNOWN without observation permission must not reserve/release another acquisition. Keep legacy codecs' behavior versioned rather than globally changing old runs.

### R13 — The oracle blueprint exceeded the available instrumentation

[make_native_sampler](../../../../isaaclab_arena/agentic_environment_generation/workflow/scene_observation.py#L465) samples world poses/velocities and narrowly filtered contact-force tensors, not contact manifolds, center-of-mass support polygons or general occlusion. [Native subject mapping](../../../../isaaclab_arena/agentic_environment_generation/workflow/native_capture.py#L452) explicitly excludes background/subasset inference. [validate_kinematic_reachability](../../../../isaaclab_arena/agentic_environment_generation/spatial_geometric_oracle.py#L380) is a radius/height heuristic over authored positions, not analytical IK. Camera/depth/instance metadata and actual support mapping require scoped implementation and empirical validation. Remove deterministic-glass-box, exact occlusion-percentage, universal support, 2 ms counterfactual and general reachability claims. A coarse geometric screen may reject a proposal only under its documented assumptions; it never substitutes for the native witness.

### R14 — Repairable generation needs both semantic and byte-level binding

[BoundedSceneModels._proposal](../../../../isaaclab_arena/agentic_environment_generation/workflow/scene_engines.py#L140) validates `ArenaEnvGraphSpec`, not the chosen repair grammar/capabilities. [repairs._target_relation](../../../../isaaclab_arena/agentic_environment_generation/workflow/repairs.py#L275) requires a unique non-anchor target, one support relation and scalar x/y. Bind a semantic selector to exact pointers against the original; retain all unauthorized fields and original-centered limits. [NativeCaptureProducer._check_spec](../../../../isaaclab_arena/agentic_environment_generation/workflow/native_capture.py#L411) permits a normalized-schema equivalence fallback only for evidence-only capture today. Preserve raw source bytes, canonical candidate bytes and validated semantic identity explicitly; do not rewrite an existing candidate merely to pass full-scene validation. Effective displacement still needs measured frame/origin/pose evidence, not just matching relation values.

### R15 — Recovery is stage reconciliation, not a resumable physics checkpoint

[restore_observations](../../../../isaaclab_arena/agentic_environment_generation/workflow/scene_ports.py#L439) and [application.resume](../../../../isaaclab_arena/agentic_environment_generation/workflow/application.py#L972) recover selected retained results and eligible unreleased continuations. The native worker does not serialize a complete resumable simulator state. After a released process crashes, a new simulator from the same seed is a new realization/effect, not continuation at the last logged step. Test lost admission ACK, committed-release/unknown-dispatch, retained-result/before-adoption, cancellation/completion races, expiry and cleanup/retention failure at the actual existing boundaries. Preserve `DiagnosticRetentionFailed` as a non-retryable retention failure and clean up even when diagnostic retention fails. Never recover by clearing metadata, dirty flags or locks.

### R16 — The proposed proof and test scopes were internally inconsistent

Two native releases can establish at most one baseline/intervention pair in the minimal G3 procedure. They cannot guarantee separate calibration, alternative acquisition, matched controls, repeatability and fault-injection witnesses. G2 must produce an explicit witness-to-case matrix and G3 must execute only its issued cases. [Plan 03's dependency order](../event_mapping/event-mapping-refactoring_plan_03.md#concrete-delivery-checkpoints) keeps supported repair and measurement validity ahead of the generated proof. The named `test_environment_workflow_scene_observation.py` does not exist; relevant tests include [scene producers](../../../../isaaclab_arena/tests/test_environment_workflow_scene_producers.py), [evidence](../../../../isaaclab_arena/tests/test_environment_workflow_evidence.py), [contracts](../../../../isaaclab_arena/tests/test_environment_workflow_contracts.py), [repairs](../../../../isaaclab_arena/tests/test_environment_workflow_repairs.py) and [trajectory assessment](../../../../isaaclab_arena/tests/test_trajectory_assessment.py). Classify actual selected checks by effects. GraphQL/Neo4j tests are not eligible for G1's zero-database scope.

### Initial supported slice versus future extension

The general data model must not bake in table-only numbers or camera names. The first owned native adapter may remain one DROID environment, supported rigid objects and world-frame/control-step measurements. Declare that limitation. Other embodiments, reference frames, physics-step sampling, event policies, modalities or batched environments are unsupported until an actual adapter is added and verified; do not present an accepted DTO as an executable capability.

Implement explicit sample/image schedules and a selected measured diagnostic before claiming adaptive acquisition. An in-worker state-driven trigger differs from a VLM-driven next view: the current split topology closes native work before model assessment, so a subsequent acquisition is a fresh owned realization/reset unless a separately implemented continuation protocol proves otherwise. Never combine different resets as one simultaneous scene.

For the reference profile, retain I01's strict final-five values and 180-step horizon as a reproducibility option. G2 must explicitly select visibility quantifiers, participating cameras and diagnostic-only captures; ALL and ANY are not interchangeable. Do not relax them after observing a failure without creating an explicitly exploratory reassessment/new case.
