# Misc Tools

This folder contains miscellaneous standalone scripts that serve various utility functions outside of core debugging and simulation pipelines:
- `list_user.py`: Parses transcript JSONL agent logs to extract user inputs.
- `make_tree.py`: Traverses and prints the hierarchy of USD scenes/prims visually.
- `verify_assets.py`: Confirms that target assets (like 'redbull') are correctly registered in the `AssetRegistry`.
